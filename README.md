# qr

Небольшой скрипт который запускаете и после этого можете вставить ссылку или текст и скрипт автоматически выдаст вам  qr-код. без редиректов и лишнего

#en

A small script that you run; after that, you can paste a link or text, and the script will automatically generate a QR code for you—no redirects or unnecessary steps.
